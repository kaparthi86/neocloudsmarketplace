01 — One-liner

Marketplace + inference layer for AI compute

Providers list GPUs and TPUs. Builders reserve capacity and call models through an OpenAI-compatible API. We turn idle and independent accelerator supply into liquid, programmatic infrastructure.

02 — Problem

Accelerator demand is exploding. Supply is scarce, opaque, and trapped.

Hyperscaler lock-in

Capacity, pricing, and regions controlled by a few clouds.

Fragmented neo-clouds

Dozens of GPU hosts with no shared discovery, trust, or API.

Buyer friction

Teams waste weeks chasing quotes, Slack DMs, and one-off contracts.

Dead inventory

Labs, colos, and smaller hosts hold chips that never reach demand.

Training and inference spend is racing ahead of the systems that price, route, and clear that capacity in an open market.

03 — Solution

Neo Clouds = accelerator exchange + inference gateway

  1. Supply side — register nodes, attest, list by hardware / region / price / workload
  2. Demand side — browse, reserve hours, run inference via /v1/chat/completions
  3. Trust layer — attestation, availability, reputation (roadmap: SLAs, escrow, payouts)
  4. Programmatic access — API keys, OpenAI-compatible interface, usage metering
Investor honesty: early access intentionally simulates reservations and inference until real provider connect and persistence ship. That is the build — not a side note.
04 — Why now

The winners of the last cloud cycle owned regions. This cycle owns liquidity.

  • Model economics force multi-cloud — no single vendor covers every training and inference profile
  • Neo-cloud proliferation — independent fleets need distribution beyond their own landing pages
  • API standardization — OpenAI-compatible endpoints made inference portable; compute should be next
  • Capital intensity — chip owners need utilization; builders need elastic access without owning clusters
  • Sovereignty — region-aware multi-provider routing is becoming a requirement

07 — Business model

Take rate on cleared compute. Margin on inference. Enterprise on trust.

Primary

Marketplace take rate on reserved compute — target 10–20% of GMV as settlement matures.

Secondary

Inference margin / routing fee on managed model endpoints.

Tertiary

Enterprise private exchanges, compliance packs, priority matching.

  • Low marginal cost to list another provider node
  • High switching cost once workloads and API keys sit on Neo Clouds
  • Network effects: more supply → better price/availability → more demand → more provider pull
08 — Go-to-market

Supply-led now. Programmatic forever.

Phase 1 — Supply-led

Warm intros → provider pilot pack → inventory waitlist → dry-run API listings.

Phase 2 — Demand density

ML startups and fine-tune shops: cheapest attested H100 in region X via one API.

Phase 3 — Programmatic

Agents and orchestrators book capacity via API — Neo Clouds becomes plumbing.

Phase 4 — Enterprise & sovereign

Private marketplaces for labs, nations, and regulated industries.
