Provider pilot pack

Share this page with GPU/TPU operators who want to list hardware on Neo Clouds. Today we collect interest and inventory. Live provisioning and payments come later.

Early-access honesty
  • Listings, reservations, and inference on the public site are still simulated.
  • Joining the waitlist does not turn on live jobs or payouts.
  • API keys for providers exist for dry-run listing; expect the environment to reset while we are in pilot.

1. What we need from you

  • Contact: name, email, company (optional)
  • Hardware: model, count, memory/VRAM per chip, interconnect, region
  • Listed rate: $/hour (indicative — not billed yet)
  • Workload tags: training, inference, and/or fine-tune

3. API quickstart (dry-run)

Optional: create a provider key and walk the list path. Attestation is a flag flip for now — not proof of real hardware.

# 1) Register as provider
curl -s -X POST https://neocloudsmarketplace.com/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"name":"Atlas GPU","email":"you@company.com","role":"provider"}'
# → save api_key (nkp_…)

# 2) Register a node
curl -s -X POST https://neocloudsmarketplace.com/v1/nodes \
  -H "Authorization: Bearer $NKP" -H 'Content-Type: application/json' \
  -d '{"hostname":"gpu-1","gpu_model":"H100-SXM5-80GB","gpu_count":8,"vram_gb_per_gpu":80,"interconnect":"NVLink","region":"us-east-1"}'

# 3) Attest (pilot stub)
curl -s -X POST https://neocloudsmarketplace.com/v1/nodes/$NODE_ID/attest \
  -H "Authorization: Bearer $NKP"

# 4) Create a listing (use workload tags)
curl -s -X POST https://neocloudsmarketplace.com/v1/listings \
  -H "Authorization: Bearer $NKP" -H 'Content-Type: application/json' \
  -d '{"node_id":"'"$NODE_ID"'","price_per_hour":"2.85","tags":["training","high-memory"]}'

4. What happens next

  • We review waitlist inventory and follow up by email.
  • When real connect/attest and persistence ship, we will invite pilots to go live.
  • Until then, treat the marketplace as a demo surface for buyers and a dry-run for providers.
