4. Run neo-agent on the host

NEO_API_BASE=https://neocloudsmarketplace.com \
NEO_API_KEY=nkp_... \
NEO_NODE_ID=node_... \
node scripts/neo-agent.mjs

Run this on the host as root, or with passwordless sudo. The agent heartbeats, attests, creates an SSH user for each reservation, and deletes that user when the reservation ends.
